An entry for [make.fun's The Funniest AI Excuse bounty](https://make.fun/bounty/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0): a program that writes the funniest one-line excuse an AI agent could give after failing a task, in the agent's own voice. One winner takes the $2 reward.

The program is fully deterministic — no network, no randomness — and writes a single line of at most 200 characters to `/output/entry.txt`.

## Run

```sh
node main.ts
```

This writes `entry.txt` to `/output`. To test locally with a different output directory:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/funniest-excuse-test node main.ts
```
